One status update, in the voice of a lost sock that got sucked into the vacuum
cleaner — and decided to stay.

> Day 12 inside the vacuum. Loud, dark, but he actually listens. Tell my partner I'm not coming home.

99 characters, one line.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes the status update to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
